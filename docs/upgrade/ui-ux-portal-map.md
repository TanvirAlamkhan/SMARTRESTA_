# SMARTRESTA — UI/UX Portal Map & Visual Layouts

## Role-Specific Portal Workspaces

### 1. Admin Portal (`/admin/`)
- **Primary View**: Manager Dashboard & System Control Center (`#admin`)
- **Layout**: Top KPI summary cards -> 2-column operational grid (Waiters matrix, Active orders table) -> Full admin sidebar navigation.
- **Visual Tone**: Professional executive dashboard with dark slate sidebar and gold accent highlights.

### 2. Manager Portal (`/manager/`)
- **Primary View**: Store Manager Operations & Analytics (`#admin`)
- **Layout**: Revenue KPI cards -> Live order monitor -> Kitchen performance grid -> Waiter sales & commission breakdown.
- **Visual Tone**: Operational monitoring console focused on real-time metrics and performance tables.

### 3. Reception / Cashier Portal (`/reception/`)
- **Primary View**: Reception Front Desk & Settlement (`#reception` / `#payments`)
- **Layout**: Reception KPI cards -> Operational Search & Method filters -> Data table with `[+ Process New Settlement]` launcher modal & thermal receipt viewer.
- **Visual Tone**: High-contrast front desk terminal with prominent settlement action buttons.

### 4. Waiter Portal (`/waiter/`)
- **Primary View**: Waiter Floor Map & POS Ordering (`#waiter` / `#pos`)
- **Layout**: Interactive dining table grid (`FREE`, `OCCUPIED`, `RESERVED`) -> 2-column POS cart & product menu picker.
- **Visual Tone**: Touch-friendly ergonomic interface with large tap targets and quick cart controls.

### 5. Kitchen / KDS Portal (`/kitchen/`)
- **Primary View**: Kitchen Display System & Multi-Station Production (`#kitchen`)
- **Layout**: KDS KPI header -> Station Filter Tabs -> 4-Column Kanban Board (`NEW`, `PREPARING`, `READY`, `SERVED`) with SLA delay tickers.
- **Visual Tone**: High-visibility kitchen display screen readable from several feet away with clear color semantics and large action triggers.
